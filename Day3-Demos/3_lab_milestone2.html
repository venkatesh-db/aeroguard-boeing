① Enforce structured JSON output inside the FastAPI backend

📖 Simple definitionThe backend never trusts the LLM's text. It checks the answer against a schema, retries if it's wrong, and only sends clean, typed JSON to the UI.
🎮 ExperienceTick the 4 build steps one at a time and press Run. Watch what reaches the technician's tablet at each stage.

② Add session / conversation memory

📖 Simple definitionThe LLM remembers nothing. The backend stores each conversation under a session_id and sends the past turns along with every new question.
🎮 ExperienceTick the steps, then chat. Without memory, "Which engine was it?" gets "I don't know". With memory, it answers.
✈️ Aviation use caseA technician troubleshoots VT-SKA over several messages without repeating the tail number, engine and findings every time.
