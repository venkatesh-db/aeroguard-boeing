Crawl → walk → run: a safe adoption roadmap

🐢 Crawl · read-only assistant

0–6 months
  • RAG over manuals, SBs and past fixes
  • Answers with citations
  • No write access to MRO systems
  • Measure: answer accuracy, time to find information

🚶 Walk · agent drafts, human approves

6–18 months
  • LangGraph agent + MCP read tools
  • Drafts work orders and handovers
  • Every write needs human approval
  • Measure: drafts accepted, errors caught

🏃 Run · orchestrated workflows

18+ months
  • Multi-agent: troubleshooting + parts + planning
  • Predictive signals feed the agent
  • Governed by audit, eval and role permissions
  • Measure: downtime, repeat defects, cost
🧭 Gate to move to the next phase: evaluation scores stable · no safety incidents · users trust it (adoption) · audit trail complete · regulator/quality team informed.
