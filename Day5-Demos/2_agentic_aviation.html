② Agent patterns: planner–executor, stop criteria, safe mode

📖 A planner breaks a goal into steps; an executor runs them one at a time and updates the state. Stop criteria (goal met, max steps, budget) prevent endless loops. Safe mode blocks or asks approval for risky "write" actions.

③ LangGraph: stateful agents as a graph

📖 LangGraph models an agent as a graph: nodes do work, edges decide what happens next (conditional routing). A shared state flows through it, checkpoints make it resumable, interrupts pause for a human, and several agents can be orchestrated.

⑤ Model Context Protocol (MCP)

📖 MCP is an open standard ("USB-C for AI") for connecting AI apps to tools and data. An MCP server exposes tools (actions), resources (read-only data) and prompts. The host app (your agent) uses an MCP client to discover and call them. Build a connector once, reuse it everywhere.

⑦ Cost optimisation: routing, caching, batching, token trimming

📖 Agents call the LLM many times per request, so costs multiply. Four levers: route easy work to small models, cache repeated answers, batch non-urgent jobs (often cheaper), and trim tokens (shorter prompts and context).
